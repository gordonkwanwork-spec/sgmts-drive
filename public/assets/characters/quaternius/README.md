`casual.glb` is the unmodified downloaded model, including its original rig,
materials and 24 animation clips. The game normalizes it to 1.75 m and turns
its forward axis at runtime. One roaming pedestrian on the A2 positive-side
footpath uses this asset. Idle, walk and run use the original baked animations.

Use `?npc=original` to compare with the original model. The local review page
is `/output/online-npc/index.html`. This is a stylized import proof, not a
photorealistic replacement for the full roster. Sketchfab required login;
the artist's Google Drive download quota was exhausted, so Poly Pizza was used.
